# Python 数据分析与清洗学习记录

本仓库用于记录我学习 Python (Pandas & Matplotlib) 的实践过程，包含从数据清洗到探索性数据分析（EDA）的完整流程。

## 📂 文件目录说明
*   `data_cleaning_practice.ipynb` - 基础数据清洗练习（处理缺失值、去重等）
*   `advanced_data_cleaning.ipynb` - 高级数据清洗实践
*   `data_analysis.ipynb` - 描述性统计、交叉分析（Groupby）及基础可视化（柱状图、饼图）

## 🛠️ 核心技术栈
*   **语言**: Python 3
*   **数据处理**: Pandas, Numpy
*   **数据可视化**: Matplotlib

## 📈 核心分析示例（基于模拟问卷数据）
1.  **描述性统计**：分析受访者的年龄分布与整体满意度（平均分 6.8）。
2.  **交叉分析**：发现江苏省满意度最高，浙江省相对较低。
3.  **分类计数与可视化**：通过饼图展示男女比例（女 57% / 男 43%）。
